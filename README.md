# RestartVPN

![RestartVPN](src/RestartVpn.App/Assets/app.png)

Монитор доступности сайтов с автоматическим перезапуском **одного** профиля
OpenVPN. Один установочный exe для Windows 7 SP1 / 10 / 11, гибкие настройки,
открытый исходный код (MIT).

> **В репозитории нет настроек и ключей.** Приложение не поставляется с
> `settings.json`, профилями, паролями или сертификатами: настройки создаются
> при первом запуске и хранятся только на машине пользователя.

> **Безопасность прежде всего.** Приложение управляет только тем профилем,
> который вы выбрали. Оно не убивает `openvpn.exe` по имени, не трогает чужие
> подключения и не меняет .ovpn, маршруты, DNS или прокси. По умолчанию
> работает в режиме «только наблюдать».

## Что умеет

* в режиме автоперезапуска поднимает выбранный профиль при старте, если он не подключён;
* проверяет сайты нативно (HTTP/HTTPS в процессе, без `curl.exe`), параллельно,
  с повтором и классификацией ошибок (DNS / TLS / таймаут / код ответа);
* перезапускает выбранный профиль OpenVPN, когда недоступны все сайты
  (или по другой кворумной политике), и **не** перезапускает при отказе одного
  сайта — это проблема сервиса, а не VPN;
* учитывает состояние туннеля по журналу OpenVPN: фатальные ошибки
  (AUTH_FAILED, TUN/TAP) не лечатся перезапуском;
* экспоненциальная пауза, джиттер, ограничение перезапусков в час и
  предохранитель после серии неудач;
* трей, пауза («snooze»), уведомления, журнал с ротацией и JSONL-события;
* JSON-настройки + графический редактор, валидация с указанием поля;
* установка для текущего пользователя без прав администратора, тихая
  установка `--install --silent`, портативный режим `--portable`.

## Требования

| | |
|---|---|
| ОС | Windows 7 SP1, Windows 10, Windows 11 |
| Среда | .NET Framework 4.8 (входит в Win10/11; на Win7 SP1 ставится отдельно) |
| VPN | OpenVPN GUI, профиль `.ovpn` |
| Права | обычный пользователь, без администратора |

Ограничения 0.1: только OpenVPN GUI (не служба), интерфейс на русском,
бинарь не подписан. Подробнее — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка

1. Скачайте `RestartVPN.exe` из Releases.
2. Запустите: exe сам предложит установку для текущего пользователя
   (`%LOCALAPPDATA%\Programs\RestartVPN`), ярлык в меню «Пуск» и, по желанию,
   автозапуск.
3. На первом запуске выберите профиль, добавьте сайты и **явно** включите
   автоперезапуск, если он нужен.

Портативно: `RestartVPN.exe --portable` — настройки и журналы рядом с exe,
в `data\`.

Удаление: Параметры → Приложения → RestartVPN, либо
`RestartVPN.exe --uninstall`.

## Быстрый старт

~~~powershell
# read-only проверка: настройки, профиль, состояние VPN, сайты
RestartVPN.exe --selftest

# работа в консоли без окна
RestartVPN.exe --headless

# один цикл проверки, без действий с VPN
RestartVPN.exe --once

# мониторинг без права трогать VPN
RestartVPN.exe --dry-run
~~~

Коды возврата: `0` — успех, `1` — ошибка/проблемы, `2` — уже запущен другой экземпляр.

## Настройки

* `%APPDATA%\RestartVPN\settings.json` — создаётся приложением, в репозитории
  его нет (в git он игнорируется);
* формат и значения по умолчанию: [docs/SETTINGS.md](docs/SETTINGS.md);
* пресеты политики: `All` (по умолчанию), `Majority`, `Any`, `Count:N`;
* `RequireTunnelEvidence: true` — перезапускать только при отказе туннеля;
* `MonitorOnly` — никогда не трогать VPN.

## Сборка и тесты

~~~powershell
dotnet build RestartVpn.sln -c Release
dotnet test tests\RestartVpn.Tests -c Release
powershell -File scripts\build.ps1      # dist\RestartVPN-<version>.exe + SHA-256
~~~

Нужен .NET SDK 8 (сборка), .NET Framework 4.8 (запуск). CI:
[.github/workflows/ci.yml](.github/workflows/ci.yml). Готовый exe не содержит
настроек — они создаются при первом запуске.

## Известные ограничения

* только OpenVPN GUI; служба OpenVPN и WireGuard — в roadmap;
* для точного сопоставления профиля используется WMI (`Win32_Process`);
* нет подписи кода и автообновления (осознанно для 0.1);
* реальные перезапуски проверялись вручную; автотесты покрывают политику,
  сопоставление профиля, пробы и настройки, но не живой туннель.
