# Changelog

## 0.1.1 — 2026-11-24

* приложение запускается **только в трее**, главное окно при старте не показывается;
* в меню трея добавлен выбор «Включить/Выключить мониторинг»;
* состояние мониторинга запоминается (`Ui.MonitoringEnabled`) и восстанавливается
  при следующем запуске;
* убран автоматический мастер первого запуска: настройки открываются из трея;
* левый клик по значку открывает меню трея.

## 0.1.0 — 2026-11-24

Первая версия.

* один exe: установка per-user, портативный режим, удаление;
* мониторинг HTTP/HTTPS без curl, классификация DNS/TLS/таймаут/код;
* политика: кворум All/Majority/Any/Count, порог, backoff, джиттер,
  ограничение в час, предохранитель;
* управление только выбранным профилем OpenVPN (`--config`), без kill по имени;
* состояние туннеля по журналу OpenVPN, режим `MonitorOnly`;
* трей, пауза, уведомления, журнал с ротацией + `events.jsonl`;
* JSON-настройки, GUI-редактор, валидация;
* 37 юнит-тестов (политика, профили, пробы, настройки, журнал);
* документация: разбор старого монитора, архитектура, настройки, миграция.

Известные ограничения: только OpenVPN GUI, UI на русском, нет подписи и
автообновления, WMI обязателен для точного сопоставления профиля.
