# Участие в разработке

Спасибо, что хотите помочь.

## Сборка

Нужен .NET SDK 8+ (Windows). .NET Framework 4.8 нужен для запуска тестов и exe.

~~~powershell
dotnet build RestartVpn.sln -c Release
dotnet test tests\RestartVpn.Tests -c Release
~~~

Релизный артефакт — один файл: `dotnet build src\RestartVpn.App -c Release`.
Core-исходники компилируются внутрь exe; если в `bin\Release\net48` появился
`RestartVpn.Core.dll`, это регресс.

## Стиль

* C# 8, `net48`, без внешних NuGet-зависимостей в приложении.
* Комментарии и имена — по-английски; пользовательский текст — по-русски.
* Политика (`DecisionEngine`) не должна делать I/O и получать время извне.
* Любое изменение, затрагивающее VPN, обязано иметь тест на безопасности:
  «похожий профиль не совпадает», «неизвестные процессы не убиваются».

## Pull request

1. Опишите сценарий и риск (особенно если меняется управление VPN).
2. Приложите `dotnet test` и, если возможно, вывод `--selftest`.
3. Не добавляйте секреты, реальные внутренние адреса и логи в репозиторий.
4. Для новых настроек обновите `docs/SETTINGS.md`. Готовые settings.json и
   ключи в репозиторий не добавляются.
