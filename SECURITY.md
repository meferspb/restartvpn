# Безопасность

## Как сообщить

Создайте issue с пометкой `security` **без** публикации эксплойта, либо
напишите мейнтейнеру. Мы постараемся ответить в течение 7 дней.

## Что в области действия

* случайное завершение чужого `openvpn.exe`;
* подмена профиля (сопоставление `--config`);
* выполнение команд из `settings.json`;
* повышение привилегий при установке/удалении;
* утечка данных (телеметрия отсутствует по дизайну).

## Модель угроз (кратко)

* приложение работает с правами пользователя (`asInvoker`), без служб;
* конфиг считается доверенным, но валидируется: только `http(s)`, без shell;
* чужой VPN не трогается: нет kill по имени образа, есть отказ при неизвестных
  командных строках;
* сеть — только запросы к целям мониторинга; обновлений и аналитики нет.

## Релизы

Бинарники 0.1 не подписаны; проверяйте SHA-256 из релиза. Подпись кода —
в roadmap (`docs/ARCHITECTURE.md`).
